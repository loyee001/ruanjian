# 等你来 · 软件与建模

孩子遇到作业卡点时，主动按下桌面按钮，通过蓝牙向家长手机求助。安卓 App 将同一条求助逐级提醒，并保留提出、回应和处理的记录。

## 分部分查看

| 部分 | 入口 | 内容 |
| --- | --- | --- |
| 软件 | [software](software/) | 安卓源码、独立模拟版、安装包与版本说明 |
| 建模 | [models](models/) | 可打印的 3MF、STL、参数化建模源码和装配说明 |
| 硬件 | [loyee001/yingjian](https://github.com/loyee001/yingjian) | ESP32 固件、GPIO23 接线、蓝牙协议和备料清单 |

软件和建模使用同一个仓库，是按提供的两个相同链接分目录整理；硬件单独存放。

## 版本与使用范围

- 已有安装包为 `0.2.1-bluetooth` 和 `0.2.1-simulation`；稳定版源码与尚在开发的新界面快照分开提供，具体构建核对见软件说明。
- 当前硬件实物接线为 **D23 / GPIO23**、3V3、GND。不要沿用早期 GPIO4 接线。
- 建模以 **V3 加宽外壳**和各配件的版本说明为准；较早托座、眼珠、嘴巴和按钮帽按各自对应接口装配。
- Android 悬浮提醒需要使用者授权。系统重要界面、隐藏覆盖层的应用及手机后台限制可能影响提醒；一键清理或强制停止后需重新打开陪伴。
- 数字模型检查与实际装配是两件事。板件厚度、插头、螺纹配合及按钮行程仍需按实物核对，主壳切片后需确认内部支撑可拆除。

本仓库不包含个人求助记录、手机调试日志、无线配对码、签名私钥或本机工具链。
